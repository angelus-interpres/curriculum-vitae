# Памятка: как править CV

Весь текст сайта лежит в одном файле — **`index.md`**. Остальные файлы трогать не нужно.

## Как внести правку

1. Откройте `index.md` и нажмите карандаш ✏️ (справа вверху над текстом).
2. Исправьте текст. На вкладке **Preview** видно, как получится.
3. Нажмите зелёную кнопку **Commit changes…**, затем ещё раз **Commit changes**.
4. Через 1–2 минуты сайт обновится. Если изменений не видно, обновите страницу с очисткой кэша: Ctrl+Shift+R (на Mac — Cmd+Shift+R).

С телефона всё делается так же, в браузере.

## Разметка

| Что нужно | Как писать |
|---|---|
| Раздел (попадает в меню наверху) | `## libelli` |
| Подраздел | `### доклады` |
| Пункт списка | `- текст` |
| Вложенный пункт с ❖ | четыре пробела, потом `- текст` |
| Нумерованный пункт | `1. текст` — можно везде писать `1.`, номера расставятся сами |
| Курсив | `*Кропинов Е. А.*` |
| Ссылка | `[текст ссылки](https://адрес)` |
| Квадратные скобки внутри ссылки | `\[Рецензия на:\]` |
| Иврит (чтобы не «прыгал» порядок слов) | `<span lang="he">אלהים</span>` |
| Скрытая строка (на сайте не видна) | `<!-- текст -->` |

Между пунктами списка пустая строка не нужна, а перед новым заголовком или после него — нужна.

## PDF

Нажмите на сайте кнопку **PDF**, затем «Сохранить как PDF». Кнопки, меню и подвал в PDF не попадут, тема всегда будет светлой.

## Если что-то сломалось

Откройте `index.md` → **History** (часы справа вверху). Там хранятся все прошлые версии: можно открыть нужную и скопировать текст обратно.

Если сайт вообще перестал обновляться: **Actions** (вкладка репозитория) — там будет красный крестик и описание ошибки.
